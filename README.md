# FASTag Automation Assignment

A Java-based Selenium automation project for validating FASTag-related web workflows.

## Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven

## What This Project Demonstrates

- UI automation and browser interaction
- Form and workflow validation
- Web element handling
- TestNG-based test execution
- Practical Selenium automation

## Run

```bash
mvn clean test
```
